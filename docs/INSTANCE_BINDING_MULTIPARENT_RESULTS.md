# 多父承载与支架直接承载工具验证

日期：2026-11-04。候选版本：v1.1.0-rc4，文件版本 1.1.0.3，运行标识 `instance-bindings-v4`。

## 最终行为

- 同一子实例允许多个承载父；“应用绑定”新增父子边并保留已有父级，同一父子对重复应用幂等。
- 快换架可直接承载 Tool，也可承载工具侧快换盘；每条边仍须接口匹配，支架仍须为 `class=station`。
- 禁止自环、跨任意父级形成的循环，以及重复父子对。解除单条关系或父组件组保留其他父级的边。
- 明细显示父级数及全部父级提示。普通确认清单列出保留的全部父级；“替换全部父组件…”明确列出被替换的所有旧父，仅保留本轮父组件。
- 编辑器、装配包预览、导出前复核、关系文件验证和 ZIP 上传使用一致的多父规则。每条边分别导出相对父组件的位姿，CAD XML 中共享子实例仍只有一个节点。
- 新关系存储及导出格式为 1.1，可读取旧 1.0 数据。新提交升级存储格式；旧插件会拒绝新格式。导出报告与关系文件必须声明相同版本；旧 1.0 单父包仍可验证，多父包不能伪装为 1.0。
