## 范围与环境

新增功能是“承载关系 → 接口属性 / 建议…”：按源文件合并编辑、向上接口下拉选择、接受接口多选、基于直接子组件生成追加建议、本机名称库和显式保存/升版。已有绑定协议和导出 JSON 格式保持 1.0；接口仍写入文件级自定义属性，沿用原导出器的角色、兼容性和发布版本校验。

实机环境：SOLIDWORKS 2025 SP5.0，API 33.5.0，官方 Interop 33.5.0.53。测试使用工作区独立模型 `artifacts/binding-ui-20261103/Binding-UI-200.SLDASM`，父资产 `ui-rack.SLDPRT`，200 个 `ui-tip.SLDPRT` 子实例。属性窗口由独立 STA WinForms 测试宿主加载生产 DLL，并通过真实 SW COM 读取/保存测试模型。

打包时尚未更新运行中的 SW 插件：用户原装配中的 `Shaker.SLDPRT` 和 `培养箱（带下翻门）.SLDASM` 在测试前已有未保存修改。用户随后手动处理并关闭 SW，明确授权继续安装；安装验证见下节。测试未修改这两份源文件。

## 证据与边界

发布包中的 `artifacts/instance-binding-ui3-evidence` 包含保存后窗口、200 条关系刷新窗口、原生取消/保存属性读回和接口库样例。`instance-binding-ui2-evidence` 保留 rc2 批量选择及链式绑定实机记录，`instance-binding-evidence` 保留原关系协议验收记录。

自动测试用故障注入覆盖写入/保存异常；本轮未在真实 SW 中制造磁盘失败。接口库是当前 Windows 用户本机名称列表，不包含团队同步、服务端发布状态查询或自动兼容性判断。实际发布仍需重新分类预览；Wanxiang 消费方联调、PDM 和其他 SW 版本不在本轮验收范围。
